# 파워 앤 플로우 (Power & Flow) — 글로벌 정치경제 50개의 대화

HR 분야 성인 대상 **글로벌 정치경제(GPE) 프로그램**
교재: *The Routledge Handbook to Global Political Economy: Conversations and Inquiries* (ed. Ernesto Vivares, Routledge 2020)

돈과 권력이 세계를 흐르는 방식 — 공급망, 환율, 무역, 탈성장, 자동화와 일자리, 조세, 이주까지.
서론과 49개 논문(챕터)마다 직접 판단하고, 배분하고, 지도에 찍어 보는 실습이 있고, 내 결과와 참가자 전체의 결과가 곧바로 도표로 그려집니다.

### 화면
- **챕터 지도** — 파트별 챕터 카드, 내 진행률, 챕터별 참여 인원
- **챕터** — 오늘의 질문 → 핵심 주장·개념 → 교재 속 도표 목록 → 실습(왼쪽 입력 / 오른쪽 실시간 결과) → 그룹 토론. 결과 패널의 ⤢ 버튼으로 프로젝터용 크게 보기
- **GPE 나침반** — 챕터 곳곳의 스펙트럼 문항을 6개 축(국가↔시장, 일국↔글로벌, 물질↔관념, 질서↔변혁, 서구↔다원, 성장↔지속가능)으로 모아 내 관점 좌표, 참가자 관점 지도(축 선택), 관점 레이더를 그립니다
- **진행 현황** — 챕터별 참여 인원, 참가자×챕터 매트릭스 (진행자용)

- 수강생 초대: `https://yalli2.github.io/gpe/?room=세션코드` (상단 메뉴의 "초대 링크 복사")

## 모드

### 1) 데모 모드 (기본)
`js/config.js`의 `firebaseDatabaseURL`이 비어 있으면 결과가 **그 브라우저에만** 저장되고, 샘플 참가자 8명이 자동으로 채워집니다. 시연·점검용입니다.

### 2) 실시간 공유 모드 (수업용)
1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 만들기 (다른 프로그램용으로 만든 것이 있으면 그대로 써도 됩니다)
2. **Build → Realtime Database → 데이터베이스 만들기**
3. **규칙(Rules)** 탭에 아래 내용을 붙여 넣고 게시
4. `js/config.js`의 `firebaseDatabaseURL`에 데이터베이스 주소 입력 후 커밋

```json
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```

> 세션 코드를 아는 누구나 읽고 쓸 수 있습니다. 닉네임만 쓰고 개인정보·회사 기밀은 적지 않도록 안내하고, 수업이 끝나면 규칙을 `false`로 바꾸거나 `rooms`를 삭제하세요.
> 다른 프로그램과 같은 Firebase를 쓸 때는 세션 코드를 겹치지 않게(예: `gpe-1105`) 정하세요.

## 파일 구조

```
index.html            진입점
css/style.css         디자인 (라이트/다크)
js/config.js          Firebase 주소 등 설정
js/meta.js            프로그램 이름 · 파트 · 나침반 6축
js/data/part*.js      챕터별 콘텐츠와 실습 정의 (서론·1–49장)
js/widgets.js         실습 입력 UI · 완료 판정 · 데모 샘플
js/charts.js          실습 유형별 실시간 차트
js/store.js           저장소 (Firebase REST 폴링 / localStorage)
js/app.js             라우팅과 화면
vendor/chart.umd.js   Chart.js 4.5.1 (MIT)
```

챕터 내용을 고치려면 `js/data/part*.js`에서 해당 챕터 객체(`n: 번호`)의 문구나 실습 항목을 수정하면 됩니다.
